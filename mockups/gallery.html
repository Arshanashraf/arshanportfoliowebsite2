Arshan Ashraf — proposed UI preview v2

Dark by default, a softened low-glare light theme, theme-aware card edges, an animated application map, and sticky stacking project cards. These are static captures, so motion reads as a single frame — the behaviours are listed below each set.

Dark (default) — sections

Cards carry a per-theme edge token, brighter than the internal hairlines, plus an inset top highlight so panels read as raised surfaces rather than flat fills.

Light (softened) — sections

Paper-toned background, raised cards in near-white, and the accent darkened to #2b6a56 so coloured text keeps its contrast on light surfaces.

What changed in v2

  • Card edges by theme. New --card-line / --card-edge tokens. Cards (hero panel, project cards, stats, contact band) use a stronger edge than inner dividers, plus an inset highlight. On hover a project card's border warms toward the accent.
  • Application map is live. The five connections are now real connector paths: the dashed strokes march along their length, two dots travel each link on a staggered loop, and an arrowhead rides the line rotated to its direction of travel.
  • Sticky stacking cards. Each project pins below the header with a small offset, so cards stack as you scroll instead of scrolling past in a bento grid.
  • Custom cursor. A 6px accent dot tracks 1:1, a 38px ring trails on a lerp with mix-blend-mode: difference, snaps magnetically to buttons, and shows a contextual label. Disabled on touch devices; text fields keep the native caret.
  • Scroll-linked progress. A single CSS custom property drives the top progress bar and section states.
  • Reduced motion. Reveals, decode, count-up, marquee, the map flow and the custom cursor all stand down under prefers-reduced-motion, and gradient text is reset so it can never render invisible.
